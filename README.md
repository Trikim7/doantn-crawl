# IUH activity bot

Bot đọc hoạt động IUH và gửi Telegram khi có hoạt động mới mở đăng ký.

Xem [hướng dẫn đầy đủ](README_IUH_BOT.md) cho cách chạy trên Ubuntu/VPS và [GitHub Actions](README_IUH_BOT.md#github-actions).

Không commit `iuh_bot.env`, mật khẩu hoặc token. GitHub Actions dùng repository Secrets, lịch tự động ban đầu tắt; chạy thử thủ công trước.
